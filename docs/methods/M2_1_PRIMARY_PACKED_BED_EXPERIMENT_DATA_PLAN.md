The 2025 Weber paper is the most relevant source for **measured Ergun pressure-loss and 1D fluid/solid heat-front response**. Published raw measurement sampling of ~60 samples/second means many temporally correlated rows, **not** thousands of independent validations. Different flow configurations and significant radial variation may make the current **1D axial model structurally insufficient**; do not fit a single effective heat-transfer coefficient to conceal radial gradients.

## Scientific comparison protocol, frozen before seeing original source responses

1. **Provenance/rights:** preserve publisher DOI/version/CC BY license and exact source-file SHA-256. Download only from original Mendeley dataset repository or original authors. Never infer data measurement authenticity from file extensions alone. The M2.1 source metadata script only queries **public API `/datasets/{id}/snapshot?version={N}`** and records access status, metadata shape, SHA-256 and file lists if available. If access fails, report **unavailable**, never silently substitute plots or simulated data. Do not commit third-party raw time histories.
2. **Original fixture geometry:** extract vessel interior L/D, particle diameter *distribution*, porosity/voidage, wall losses, material density/cp, sensor positions, pressure tap locations. The existing `PackedBedGeometry` assumes uniform spherical particles and **d_particle ≤ D/5**. If measured particle size/shape or near-wall effects make this invalid, record a structural modelling limitation rather than forcing the data into that geometry.
3. **Time origin, inlet and thermocouple orientation:** verify original time units, first accepted heating/cooling timestamps, thermocouple axial and radial location, signal sampling rate and calibration. For each run, preserve measured physical time history `T_in(t)` instead of imposing an idealized constant inlet temperature or designing the boundary from the heldout output. Record whether sensors are gas temperature, solid/particle temperature, wall or outlet plenums. The current `GasRockBed` has **two separate phase temperatures per cell**—mapping the wrong phase is not a valid comparison.
4. **Pressure boundary:** determine whether the original differential pressure is across the **bed itself** or across the bed + distributors, mesh, duct, inlet/outlet effects. Obtain a **measured clean-bed/fittings pressure-loss correction** or keep Ergun agreement *unverified*. With documented air density/viscosity and mass-flow units, calculate superficial velocity `u = m_dot/(rho A)` and compare the original no-fit Ergun prediction. Never fit Ergun coefficients using a pressure-holdout run and then claim its result is independent.
5. **Predeclared independent split:** use experiment **run IDs/folders**, not arbitrary timestamp rows or different thermocouple channels. Assign at least two entire experiment runs to training and two to previously reserved validation; the fitted model may only use calibration runs. If different inlet directions/topologies are involved, separate the physics and holdout classes; no cross-apparatus pooling. Group assignment must use source **operating inputs** only, not observed breakthrough/pressure-loss scores.
6. **In-domain vs extrapolation:** assess measured-input support using a convex hull of **mass flow, inlet and initial temperature and geometry/material class**. A bounding rectangle is insufficient. A reserved test outside the multidimensional training hull is **external stress testing**, not interpolation evidence. For a fixed apparatus, too few independent points to span the input dimension should be explicitly reported as insufficient.
7. **Independent predictions:** run the current conservative `GasRockBed` solver with measured time-dependent inlet/flow and original geometry/material values **without fitting to heldout traces**. Export predicted temperature at original TC axial position and exact measured sample times (or predeclared time interpolation), thermocline breakthrough time for pre-specified fractions (10%, 50%, 90%), MAE/RMSE/bias by sensor and run. For a shallow aspect ratio and radial TC gradients, compare axial mean and radial spread separately; a 1D model must report its unresolved cross-section heterogeneity.
8. **Uncertainty/reproducibility:** report thermometer standard uncertainty, TC placement uncertainty, pressure transmitter/flowmeter calibration, sample time synchronization and source pressure corrections separately. If a reported bound is an accuracy/specification rather than standard uncertainty, **do not claim 1σ equivalence without a justified coverage/distribution model**. Assess temporal sample autocorrelation by run-level bootstrap / experiment-level uncertainty; never treat 60 Hz values as statistically independent.
9. **Model fidelity and numerical convergence:** maintain distinct criteria for (a) finite-volume conservation and mesh/time-step convergence, (b) thermocouple alignment and original measured accuracy, (c) pressure loss and piping correction, (d) application transfer to H-REF geometry/thermodynamics. Numerical solver success is **verification, not experimental validation**. Keep any fitted wall UA/particle heat-transfer parameters frozen before scoring the reserved cases.
10. **Acceptance:** only accept a complete original dataset when individual time traces, calibration, exact source geometry, measured pressure tap correction, **and** withheld run-level predictions are all reproducibly evaluated. Any missing piece yields `NOT_VALIDATED`. Even a successful off-target lab bed does not demonstrate **1 MW industrial heating, process-liquid HX, thermal discharge duty, RTE or coupled compressor feasibility**.

## What has been implemented now

- `scripts/discover_m2_packed_bed_original_data.py`: two original data DOI/version registries, public source license and metadata, optional bounded API fetch and original metadata SHA-256; emits **no raw observations**.
- `src/carnot_battery_lab/physics/packed_bed_measurement_gate.py`: typed strict original sensor history and calibration admission, physical TC coordinate/time monotonicity, full experiment group split, pressure-loss corrections and explicit no-fit Ergun diagnostic, no-false-claim time-aligned thermocouple error metrics.
- `tests/test_m2_1_packed_bed_measurement_gate.py`: synthetic **adversarial** fixtures only, never empirical test claims; invalid sensor positions, duplicated records, time drift ordering, missing flow calibration, zero/negative pressure, inability to substitute synthetic data, unsupported pipe pressure loss and train/holdout leakage.
- `.github/workflows/m2-1-primary-packedbed-experimental-evidence.yml`: reproducible source-discovery metadata and tests, clearly marked as **not measured breakthrough validation**.
